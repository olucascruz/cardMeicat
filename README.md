# 💳 Cartão de Visita 3D - Meicat

Visualizador 3D de um **cartão de visita** da marca **Meicat**, desenvolvido com [Three.js](https://threejs.org/) e modelado no [Blender](https://blender.org). O projeto permite que o usuário interaja com o cartão girando-o com o mouse, proporcionando uma experiência visual mais imersiva.

## 🔗 Acesse o projeto

Disponível em: [https://olucascruz.github.io/cardMeicat/](https://olucascruz.github.io/cardMeicat/)
## 🧰 Tecnologias

- Three.js
- GLTFLoader
- OrbitControls
- Blender (modelagem 3D)
- Vite (build e desenvolvimento)
- GitHub Pages (deploy)


## ▶️ Como rodar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/olucascruz/cardMeicat.git
   cd cardMeicat
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Execute o vite:
   ```bash
   npx vite
   ```
